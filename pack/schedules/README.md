# On-demand offline timetable pack

Run `npm run build:timetables -- --input /path/to/licensed-zips --output /path/to/staging` using only official, downloaded GTFS archives. The builder reads `packages/timetables/src/licence-allowlist.json`; do not add agencies without a confirmed licence review. In production, the default input is `/workspace/shared/access-data/transit/metrolinx/2026-11-15/`, where the executor stores the official downloads outside Git. The builder does not download feeds, and no original ZIP is committed. An unlisted zip is ignored.

Data paths are relative to `data/schedules/v1/`. Every gzip part is checked against the manifest SHA-256 and byte count before parsing. The Journey consumer reads only parts already in HTTP Cache Storage, or an explicitly injected test provider; it cannot trigger a network download. A region downloader must copy verified chunks from `placement: git` paths or `placement: release` assets into the HTTP cache using the manifest path as its cache key. On cancellation or deletion of a release asset, remove the corresponding cached parts and manifest rows. `missingChunks(regionId)` lists cache misses. This package does not provide realtime arrivals or step-free route graph decisions; those belong to Journey.

**First install:** `data/schedules/**` is not a shell import and must never be included in service-worker precache. Schedule data is downloaded on demand per region; none of it counts against the 3.95 MiB initial install. The builder targets a roughly 150 MB git allocation for additional chunks; remaining shards are release assets in `release-assets/` and `RELEASE-ASSETS.md`. The executor must upload the listed assets to a GitHub release with unchanged filenames before publishing the manifest.

**Licence exclusions:** MiWay is **UNCLEAR**, `inWebPack: false`: official terms href not confirmed; grantor defect in the still-hosted PDF. Do not download or pack it. Any other source missing confirmed licence fields in the PR #1 registry is also held and must be logged before building. Currently the allow-list includes LTC (LTC Open Data Terms of Use, retrieved 2026-11-15) and the two expressly AUA-accepted static feeds; other operators may be added only after copying their verified licence and retrieval details from `sources/registry.json`.

**Metrolinx separation and terms:** `metrolinx-go` (GO Transit) and `metrolinx-up` (UP Express) are packed in exclusive, removable release files (`placement: release`), even under the git size budget. Their licence is `Metrolinx Access and Use Agreement (accepted 2026-11-15)`. The following section 3 legend must be shown prominently anywhere their scheduled times appear:

> Data used in this product or service is provided with the permission of Metrolinx. Metrolinx makes no representations or warranties of any kind, express or implied, with respect to the Data and assumes no responsibility for the accuracy or currency of the data used in this product or service.

Also display the OGL line:

> Contains information licensed under the Open Government Licence - Ontario - Metrolinx.

The data is not live; display each departure's source name and retrieved date. End users must follow applicable laws; use the English and French terms exported by the package. Do not use transit agency marks or imply sponsorship. See `/workspace/shared/access-superapp/review/metrolinx-removal-runbook.md` for the removal procedure, and `/workspace/shared/access-superapp/review/metrolinx-AUA-acceptance.md` and `/workspace/shared/access-superapp/review/metrolinx-AUA-copy-2026-11-15.md` for the recorded acceptance and terms.

**Build on 2026-11-15:** Official `GO-GTFS.zip` and `UP-GTFS.zip` were packed from `/workspace/shared/access-data/transit/metrolinx/2026-11-15/` into 165 release assets (all under 20 MB, none in git, none in the 3.95 MiB first install). Filenames, byte counts and SHA-256 hashes are in `RELEASE-ASSETS.md` and `manifest.json`. The binaries themselves are not committed; they must be uploaded to a GitHub release with unchanged filenames before the manifest is published. LTC is on the allow-list (LTC Open Data Terms of Use, retrieved 2026-11-15) but `google_transit.zip` was not in the input directory, so it was skipped (`ltc: zip missing` in `BUILD-REPORT.json`). Re-run the builder with that official zip present to add LTC git-placed chunks. MiWay was not packed.
