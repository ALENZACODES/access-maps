# Service notice snapshots / Fichiers d’avis de service

## English

Open the calendar, then choose a local snapshot from this directory. Compressed files ending in `.ndjson.gz` open directly. The fictional example is available without a file. [Open the service notice calendar](../../docs/attribution/notice-calendar.html?lang=en)

Choose the first date, the number of days (1–31) and the time zone. Apply the selection, then choose a day to see its notice periods. A period that crosses midnight appears on both dates. Each entry opens to show the original bounds, source, licence, retrieval date and source tier. The source’s original wording and language are retained.

The two groups below the day list distinguish notices with insufficient timing information from notices whose published periods fall outside the selection. Missing values appear as `UNKNOWN`. An empty day reports only what the file contains. The text download covers every selected date and every matching notice, including entries on later pages.

The reader accepts a JSON array, a single JSON notice, or newline-delimited JSON, optionally compressed with gzip. The file limit is 4 MiB, with a limit of 8 MiB after decompression and 5,000 notices per file.

## Français

Ouvrez le calendrier, puis choisissez un fichier local dans ce dossier. Les fichiers compressés portant l’extension `.ndjson.gz` s’ouvrent directement. L’exemple fictif est accessible sans fichier. [Ouvrir le calendrier des avis de service](../../docs/attribution/notice-calendar.html?lang=fr)

Choisissez le premier jour, le nombre de jours (de 1 à 31) et le fuseau horaire. Appliquez ces choix, puis sélectionnez un jour pour consulter les périodes des avis. Une période qui traverse minuit apparaît aux deux dates. Ouvrez un avis pour consulter les limites d’origine, la source, la licence, la date de collecte et le niveau de la source. Le texte original conserve sa langue.

Les deux groupes sous la liste distinguent les avis dont l’horaire demeure inconnu et ceux dont les périodes publiées tombent en dehors des dates choisies. Les valeurs manquantes portent la mention `UNKNOWN`. Une journée vide décrit uniquement le contenu du fichier. Le rapport texte comprend toutes les dates choisies et tous les avis correspondant aux filtres, y compris les entrées des pages suivantes.

Le calendrier accepte un tableau JSON, un avis JSON ou un fichier contenant un avis JSON par ligne, avec ou sans compression gzip. La limite est de 4 Mio par fichier, de 8 Mio après décompression et de 5 000 avis par fichier.
