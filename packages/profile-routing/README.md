# @access-maps/profile-routing

Pure TypeScript, on-device distance routing for the App. No tiles, timetables, live traffic, APIs, account system or network requests ship with this library. No transit-time calculation or inferred geometry-derived slope is performed. It is not a live navigation or safety guarantee.

`route(profile, fromNodeId, toNodeId, segments, { paceMps: 1.0 })` returns shortest *known-distance* traversable legs, an estimated rolling duration in seconds, refusals and UNKNOWN flags. The **editable** default pace is **1.0 m/s**, only an estimate, never a medical recommendation. `allowUnknownSegments` defaults to `false`. Opting in permits unknown slope/width/surface, but never a known incompatible fact, recorded steps or unknown distance. Missing step evidence is labelled Unknown rather than silently converted to step-free; it is not a gate because the specified opt-in covers the three required surface/path facts. No duration is inferred from `breakIntervalMinutes`.

`approach(profile, { id, doorNodeId }, segments, radiusM = 200)` examines sourced facts on complete segments within a 200 m *network-distance* radius of a place door. Each segment gets a per-need known-yes / known-no / Unknown list and the `byNeed` conservative overview returns Unknown if evidence is missing or mixed with unknown. This is a nearby-branch inspection, **not** a promised door-to-origin route or a single accessibility score. Segments without sourced lengths are not included; missing evidence should not be taken as an accessible approach. The caller must supply the actual connected sidewalk graph and accessible door node; no map matching is fabricated.

Segments use the provenance field shape `{ value | "UNKNOWN", source_id, licence, retrieved_at, tier, source_key?, raw?, derived? }`. Tier 0 (unverified draft), invalid provenance, and missing facts are Unknown, even when a numeric value is present. This package never promotes a tier. Evidence and names must come from the caller's licensed source registry; the test dataset is synthetic CC0 only. Only ODbL, OGL-Ontario, OGL-Canada, CC-BY and CC0 licences are accepted. Keep **ODbL-derived records siloed** from OGL/CC records in source storage/exports and preserve ODbL share-alike obligations; display `© OpenStreetMap contributors, ODbL` alongside OSM-derived facts. Each surfaced fact should display its source, licence, retrieved date and tier (EN/FR labels provided in `src/strings.ts`). Nothing here exports or publishes community reports.

Use the existing workspace Vitest installation to run `vitest run packages/profile-routing/test`. There is no UI and therefore no new axe surface. No new dependencies are introduced.
